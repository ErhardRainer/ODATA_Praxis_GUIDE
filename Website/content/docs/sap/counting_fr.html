SAP › Comptage des Enregistrements

Il existe deux façons d'obtenir le nombre d'enregistrements dans OData, chacune répondant à un objectif différent.

$inlinecount (Paramètre)

Renvoie les données et le nombre total d'enregistrements (en ignorant $top et $skip) dans une seule charge utile (payload).

/SalesOrders?$inlinecount=allpages

Idéal pour construire des composants de pagination dans l'interface utilisateur.

$count (Ressource)

Renvoie uniquement un nombre simple (text/plain) représentant le total. Ne renvoie aucune donnée.

/SalesOrders/$count

Idéal pour les badges ou les compteurs rapides sur un tableau de bord.

Impact sur les Performances

Le comptage peut être lent sur les grandes tables dans SAP. Le système doit d'abord effectuer un SELECT COUNT(*) sur la base de données avant de récupérer les données pour les paramètres $top et $skip. À n'utiliser que si nécessaire.
