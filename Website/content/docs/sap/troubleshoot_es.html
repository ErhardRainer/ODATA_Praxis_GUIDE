SAP › Solución de Problemas

Problemas comunes al trabajar con servicios SAP OData y cómo resolverlos.

Error: "Property 'X' is not a valid property"

Es probable que esté utilizando un nombre de propiedad que no existe en el EntityType. Compruebe la distinción entre mayúsculas y minúsculas (p. ej., SalesOrder frente a salesOrder). OData distingue entre mayúsculas y minúsculas.

Error: "Filter not supported" o Opción de Consulta de Sistema No Válida

Es posible que la propiedad prohíba estrictamente el filtrado (sap:filterable="false"). O bien, puede que esté utilizando un operador no admitido por la implementación del gateway (p. ej., substringof en un campo numérico).

Datos Faltantes / Duplicados en la Paginación

Este es un síntoma clásico de una ordenación no determinista. Añada una clave única a su cláusula $orderby.

HTTP 401 Unauthorized / 403 Forbidden

Verifique sus credenciales. Compruebe también si el usuario SAP tiene los roles PFCG y los objetos de autorización (S_SERVICE) necesarios para acceder al servicio OData específico.
