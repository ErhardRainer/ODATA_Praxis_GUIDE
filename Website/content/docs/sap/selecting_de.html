Selektieren & Erweitern

$select

Verwenden Sie $select, um nur die Felder zurückzugeben, die Sie tatsächlich benötigen. Dies reduziert die Payload-Größe und verbessert die Performance erheblich.

?$select=SalesOrder,Customer,Amount

$expand

Verwenden Sie $expand, um verknüpfte Entitäten in einem einzigen Request mitzuladen. Das vermeidet den "N+1 Query"-Effekt.

?$expand=to_Items

Kombination von beidem

In SAP OData können Sie Felder aus der Hauptebene und der erweiterten Ebene gleichzeitig einschränken:

?$select=SalesOrder,to_Items/Material,to_Items/Quantity&$expand=to_Items

* Hinweis: In OData V4 ist die Syntax für verschachteltes Select etwas anders: $expand=to_Items($select=Material,Quantity).
