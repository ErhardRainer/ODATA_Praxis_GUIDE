SAP › 元数据 ($metadata)

$metadata 端点是您的 API 蓝图。它描述了服务的完整架构——实体类型、属性、关系和能力。

访问元数据：

GET /sap/opu/odata/sap/API_SALES_ORDER_SRV/$metadata

里面有什么？

  • EntityType 定义结构：属性、数据类型和键。可以将其视为类定义。
  • EntitySet EntityType 实例的命名集合。这就是您在 URL 中查询的内容。
  • NavigationProperty 定义实体之间的关系（例如，SalesOrder → SalesOrderItem）。

值得注意的 SAP 注解

注解 含义
sap:filterable="false"不能在 $filter 中使用此属性
sap:sortable="false"不能在 $orderby 中使用此属性
sap:creatable="false"不能在 POST 期间设置此属性
sap:required-in-filter="true"必须在 $filter 中包含此属性

务必先检查元数据： 在构建查询之前，请查看 $metadata 以了解字段限制。尝试在不可过滤的字段上进行过滤将返回错误。
