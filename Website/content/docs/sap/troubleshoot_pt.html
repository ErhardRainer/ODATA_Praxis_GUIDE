Problemas comuns ao trabalhar com serviços SAP OData e como resolvê-los.

Erro: "Property 'X' is not a valid property"

É provável que você esteja usando um nome de propriedade que não existe no EntityType. Verifique a diferenciação entre maiúsculas e minúsculas (ex: SalesOrder vs salesOrder). O OData diferencia maiúsculas de minúsculas.

Erro: "Filter not supported" ou Parâmetro de Consulta de Sistema Inválido

A propriedade pode proibir estritamente a filtragem (sap:filterable="false"). Ou você pode estar usando um operador não suportado pela implementação do gateway (ex: substringof em um campo numérico).

Dados Ausentes / Duplicatas na Paginação

Este é um sintoma clássico de ordenação não determinística. Adicione uma chave única à sua cláusula $orderby.

HTTP 401 Unauthorized / 403 Forbidden

Verifique suas credenciais. Além disso, verifique se o usuário SAP tem as funções PFCG e objetos de autorização (S_SERVICE) necessários para acessar o serviço OData específico.
