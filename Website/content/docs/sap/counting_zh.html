SAP › 记录计数

在 OData 中有两种获取记录计数的方法，每种方法都有不同的用途。

$inlinecount (参数)

在单个有效负载中返回数据以及总记录数（忽略 $top 和 $skip）。

/SalesOrders?$inlinecount=allpages

非常适合在 UI 中构建分页组件。

$count (资源)

仅返回一个表示计数的简单数字 (text/plain)。不返回任何数据。

/SalesOrders/$count

非常适合仪表板上的徽章或快速计数器。

性能影响

在 SAP 的大型表中，计数可能会很慢。系统必须先在数据库上执行 SELECT COUNT(*)，然后才能检索 $top 和 $skip 参数的数据。仅在必要时使用。
