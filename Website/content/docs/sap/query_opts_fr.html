SAP › Aide-mémoire des Options de Requête

Les options de requête vous permettent de filtrer, trier, paginer et mettre en forme les données renvoyées par les services OData. Toutes les options commencent par $.

$filter

Restreint les résultats aux entités correspondant à une condition.

$filter=SalesOrderType eq 'OR' and TotalNetAmount gt 1000

$select

Renvoie uniquement les propriétés spécifiées, réduisant ainsi la taille de la charge utile.

$select=SalesOrder,CustomerID,NetValue

$orderby

Trie les résultats. Utilisez asc ou desc.

$orderby=CreationDate desc,SalesOrder asc

$top & $skip

Contrôles de pagination. $top limite les résultats ; $skip décale le point de départ.

$top=50&$skip=100

$count / $inlinecount

Obtenez le nombre total d'entités correspondantes.

/A_SalesOrder/$count ?$inlinecount=allpages

$format

Spécifiez le format de réponse. La valeur par défaut est généralement Atom/XML dans OData v2.

$format=json
