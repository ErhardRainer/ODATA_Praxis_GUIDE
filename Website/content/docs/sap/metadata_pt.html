SAP › Metadados ($metadata)

O endpoint $metadata é o projeto da sua API. Ele descreve o esquema completo do serviço — tipos de entidade, propriedades, relacionamentos e capacidades.

Acessando Metadados:

GET /sap/opu/odata/sap/API_SALES_ORDER_SRV/$metadata

O que há dentro?

  • EntityType Define a estrutura: propriedades, tipos de dados e chaves. Pense nisso como uma definição de classe.
  • EntitySet Uma coleção nomeada de instâncias de EntityType. É o que você consulta nas URLs.
  • NavigationProperty Define relacionamentos entre entidades (ex: SalesOrder → SalesOrderItem).

Anotações SAP a Observar

Anotação Significado
sap:filterable="false"Não é possível usar esta propriedade em $filter
sap:sortable="false"Não é possível usar esta propriedade em $orderby
sap:creatable="false"Não é possível definir esta propriedade durante o POST
sap:required-in-filter="true"Deve incluir esta propriedade em $filter

Sempre Verifique os Metadados Primeiro: Antes de construir consultas, revise o $metadata para entender as restrições de campo. Tentar filtrar em um campo não filtrável retornará um erro.
