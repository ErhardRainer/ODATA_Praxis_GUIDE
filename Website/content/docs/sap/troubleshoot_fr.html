Problèmes courants rencontrés lors de l'utilisation des services SAP OData et comment les résoudre.

Erreur : "Property 'X' is not a valid property"

Vous utilisez probablement un nom de propriété qui n'existe pas dans l'EntityType. Vérifiez la casse (ex. SalesOrder vs salesOrder). OData est sensible à la casse.

Erreur : "Filter not supported" ou Option de Requête Système Invalide

La propriété peut interdire strictement le filtrage (sap:filterable="false"). Ou vous utilisez peut-être un opérateur non pris en charge par l'implémentation du gateway (ex. substringof sur un champ numérique).

Données Manquantes / Doublons dans la Pagination

C'est un symptôme classique d'un tri non déterministe. Ajoutez une clé unique à votre clause $orderby.

HTTP 401 Unauthorized / 403 Forbidden

Vérifiez vos identifiants. Vérifiez également si l'utilisateur SAP possède les rôles PFCG et les objets d'autorisation (S_SERVICE) requis pour accéder au service OData spécifique.
