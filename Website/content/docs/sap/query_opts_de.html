System-Abfrageoptionen

Abfrageoptionen ermöglichen es Ihnen, die vom Server zurückgegebenen Daten zu filtern, zu sortieren und zu formatieren. Diese beginnen immer mit einem Dollarzeichen $.

Option Beschreibung Beispiel
$filter Filtert die Ergebnismenge basierend auf Bedingungen. status eq 'A'
$select Gibt nur die angegebenen Felder zurück. ID,Name,Date
$expand Lädt verknüpfte Entitäten inline (Joins). to_Items,to_Header
$orderby Sortiert die Ergebnisse (asc/desc). CreatedAt desc
$top / $skip Wird für Paginierung verwendet. $top=10&$skip=20
$format Fordert JSON oder XML an (standardmäßig oft XML bei SAP). json

Wichtig: Sie können mehrere Optionen mit dem & Zeichen kombinieren. Der erste Parameter nach dem Pfad muss jedoch immer mit einem ? eingeleitet werden.
