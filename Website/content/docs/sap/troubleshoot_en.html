SAP › Troubleshooting

Common issues when working with SAP OData services and how to resolve them.

Error: "Property 'X' is not a valid property"

You are likely using a property name that doesn't exist in the EntityType. Check the case sensitivity (e.g., SalesOrder vs salesOrder). OData is case-sensitive.

Error: "Filter not supported" or Invalid System Query Option

The property might strictly prohibit filtering (sap:filterable="false"). Or, you might be using an operator not supported by the gateway implementation (e.g., substringof on a numeric field).

Missing Data / Duplicates in Paging

This is a classic symptom of non-deterministic sorting. Add a unique key to your $orderby clause.

HTTP 401 Unauthorized / 403 Forbidden

Verify your credentials. Also check if the SAP user has the required PFCG roles and authorization objects (S_SERVICE) to access the specific OData service.
