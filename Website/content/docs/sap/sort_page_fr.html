SAP › Tri et Pagination

Une pagination correcte nécessite un tri déterministe. Sans $orderby, l'ordre des enregistrements est indéfini, ce qui peut entraîner des doublons ou des omissions d'enregistrements lors de la pagination.

Tri ($orderby)

Triez les résultats à l'aide de asc (croissant) ou desc (décroissant).

$orderby=CreationDate desc,SalesOrder asc

Pagination ($top & $skip)

  • $top=n: Renvoie les n premiers enregistrements.
  • $skip=n: Ignore les n premiers enregistrements.
$top=50 // 50 premiers enregistrements
$top=50&$skip=50 // Enregistrements 51-100
$top=50&$skip=100 // Enregistrements 101-150

Crucial pour la Pagination

Triez toujours par une clé unique !

Si vous triez par un champ non unique (ex. date), les enregistrements ayant la même date peuvent changer d'ordre entre les requêtes. Ajoutez toujours un critère de départage unique comme la clé primaire :
$orderby=CreationDate desc, SalesOrderID asc
