SAP › संदर्भ अवलोकन

OData (Open Data Protocol) क्वेरी करने योग्य API बनाने और उपभोग करने के लिए एक मानकीकृत REST-आधारित प्रोटोकॉल है। SAP पारिस्थितिकी तंत्र में, OData SAP गेटवे को शक्ति प्रदान करता है, जिससे बाहरी एप्लिकेशन SAP व्यावसायिक डेटा और प्रक्रियाओं के साथ इंटरैक्ट कर पाते हैं।

RESTful डिज़ाइन

मानक HTTP विधियों (GET, POST, PUT, DELETE) का उपयोग करता है और REST सम्मेलनों का पालन करता है।

क्वेरी सक्षम

फ़िल्टरिंग, सॉर्टिंग, पेजिंग और विशिष्ट फ़ील्ड चुनने के लिए समृद्ध क्वेरी विकल्प।

स्व-वर्णन

$metadata एंडपॉइंट सेवा के लिए पूर्ण स्कीमा जानकारी प्रदान करता है।

SAP OData का उपयोग क्यों करता है

  • मानकीकरण: सेवाओं के बीच सुसंगत व्यवहार।
  • इंटरऑपरेबिलिटी: किसी भी HTTP क्लाइंट के साथ काम करता है।
  • Fiori एकीकरण: Fiori ऐप्स के लिए नेटिव API लेयर।
