SAP › Métadonnées ($metadata)

Le point de terminaison $metadata est le plan de votre API. Il décrit le schéma complet du service — types d'entités, propriétés, relations et capacités.

Accès aux Métadonnées :

GET /sap/opu/odata/sap/API_SALES_ORDER_SRV/$metadata

Qu'est-ce qu'il y a à l'intérieur ?

  • EntityType Définit la structure : propriétés, types de données et clés. Considérez cela comme une définition de classe.
  • EntitySet Une collection nommée d'instances de EntityType. C'est ce que vous interrogez dans les URL.
  • NavigationProperty Définit les relations entre les entités (ex : SalesOrder → SalesOrderItem).

Annotations SAP à Surveiller

Annotation Signification
sap:filterable="false"Impossible d'utiliser cette propriété dans $filter
sap:sortable="false"Impossible d'utiliser cette propriété dans $orderby
sap:creatable="false"Impossible de définir cette propriété lors du POST
sap:required-in-filter="true"Doit inclure cette propriété dans $filter

Vérifiez toujours les métadonnées en premier : Avant de construire des requêtes, examinez le $metadata pour comprendre les restrictions de champ. Tenter de filtrer sur un champ non filtrable retournera une erreur.
