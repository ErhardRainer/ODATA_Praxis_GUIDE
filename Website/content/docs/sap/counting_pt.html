SAP › Contagem de Registros

Existem duas maneiras de obter a contagem de registros em OData, cada uma servindo a um propósito diferente.

$inlinecount (Parâmetro)

Retorna os dados e o número total de registros (ignorando $top e $skip) em um único payload.

/SalesOrders?$inlinecount=allpages

Ideal para construir componentes de paginação na interface do usuário.

$count (Recurso)

Retorna apenas um número simples (text/plain) representando a contagem. Não retorna dados.

/SalesOrders/$count

Ideal para badges ou contadores rápidos no dashboard.

Impacto na Performance

Contar pode ser lento em tabelas grandes no SAP. O sistema deve primeiro realizar um SELECT COUNT(*) no banco de dados antes de buscar os dados para os parâmetros $top e $skip. Use apenas quando necessário.
