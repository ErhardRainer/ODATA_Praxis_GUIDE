SAP › ソートとページング

適切なページングには、決定論的なソートが必要です。$orderby を指定しない場合、レコードの順序は定義されず、ページング時にレコードの欠落や重複が発生する可能性があります。

ソート ($orderby)

asc (昇順) または desc (降順) を使用して結果をソートします。

$orderby=CreationDate desc,SalesOrder asc

ページング ($top & $skip)

  • $top=n: 最初の n 件のレコードを返します。
  • $skip=n: 最初の n 件のレコードをスキップします。
$top=50 // 最初の 50 レコード
$top=50&$skip=50 // 51～100 レコード
$top=50&$skip=100 // 101～150 レコード

ページングにおける重要事項

必ずユニークキーでソートしてください！

ユニークでないフィールド（例：日付）でソートすると、リクエスト間で同じ日付を持つレコードの順序が変わる可能性があります。必ず主キーなどのユニークな項目を追加して順序を確定させてください：
$orderby=CreationDate desc, SalesOrderID asc
