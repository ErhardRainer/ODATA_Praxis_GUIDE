SAP › Reference Overview

OData (Open Data Protocol) is a standardized REST-based protocol for building and consuming queryable APIs. In the SAP ecosystem, OData powers SAP Gateway, enabling external applications to interact with SAP business data and processes.

RESTful Design

Uses standard HTTP methods (GET, POST, PUT, DELETE) and follows REST conventions.

Query Capable

Rich query options for filtering, sorting, paging, and selecting specific fields.

Self-Describing

The $metadata endpoint provides complete schema information for the service.

Why SAP Uses OData

  • Standardization: Consistent behavior across services.
  • Interoperability: Works with any HTTP client.
  • Fiori Integration: Native API layer for Fiori apps.
