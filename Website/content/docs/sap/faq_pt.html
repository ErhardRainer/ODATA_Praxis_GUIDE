SAP › Perguntas Frequentes (FAQ)

Qual é a diferença entre OData v2 e v4 no SAP?

O OData v2 é o padrão para a maioria das implementações do SAP Gateway. O v4 é o padrão mais novo e eficiente usado em sistemas S/4HANA modernos. O v4 oferece melhor performance, metadados simplificados e capacidades de consulta mais poderosas.

Por que estou recebendo erros de 'Property cannot be filtered'?

Isso acontece quando um campo está marcado com sap:filterable="false" no $metadata. O SAP frequentemente restringe a filtragem em campos calculados ou campos de texto grandes para garantir o desempenho do banco de dados.

Como lidar com a autenticação para chamadas OData?

O SAP suporta Basic Auth, OAuth 2.0 (recomendado) e SAML. Para aplicativos baseados em navegador, a Propagação de Principal é frequentemente usada. Sempre use HTTPS para proteger as credenciais.

Qual é o número máximo de registros que posso recuperar?

Os sistemas SAP geralmente têm limites no lado do servidor (ex: 1.000 registros). Se você precisar de mais, deverá usar a **paginação** (seguindo o link __next ou usando $skip/$top).

Como faço para chamar funções ou ações OData?

Funções (GET) e Ações (POST) são operações personalizadas definidas no $metadata. Você as chama anexando o nome à URL do serviço, ex: .../GetQuickStats() ou .../ReleaseOrder.

Posso atualizar vários registros em uma única solicitação?

Sim, usando as **solicitações em lote OData** ($batch). Você pode agrupar várias operações GET, POST, PATCH ou DELETE em um único POST HTTP. O SAP suporta processamento atômico (tudo ou nada) e não atômico usando tipos de conteúdo multipart/mixed.

Como lidar com deep inserts (criação de entidades relacionadas)?

Os deep inserts permitem criar entidades pai e filho (como uma Ordem de Venda e seus Itens) em uma única solicitação POST, aninhando os dados do filho dentro da estrutura JSON do pai.

O que significa o erro do token CSRF?

O SAP exige um token CSRF para todas as solicitações que alteram o estado (POST/PUT/DELETE). Você deve primeiro buscar um token via uma solicitação GET com o cabeçalho x-csrf-token: fetch e, em seguida, enviar o token recebido de volta em sua solicitação de gravação subsequente.

Conceitos Legados

EntitySet vs. EntityType?

EntityType é a "Classe" (Modelo), EntitySet é a "Tabela" (Coleção de instâncias).

JSON vs. XML?

Sempre prefira JSON. É mais leve, mais rápido de processar e usa menos largura de banda.
