SAP OData › 最佳实践

遵循这些准则，确保您的 SAP OData 集成是高效、可扩展且对系统性能友好的。

有选择性地使用 ($select)

“永远不要索取你不需要的东西。”

SAP Gateway 必须从数据库中检索每个字段并将其转换为 XML/JSON。通过使用 $select，您可以大幅减少 ABAP 处理时间和在网络上传输的数据包大小。

尽早过滤，始终过滤 ($filter)

“让数据库来完成繁重的工作。”

永远不要获取 10,000 条记录却只在 JavaScript 代码中过滤出 10 条。使用 OData 过滤器确保 SAP 执行优化的 SQL 语句，并仅返回严格需要的内容。

确定性分页

“一致性是良好用户体验的关键。”

始终将 $top 和 $skip 与包含至少一个唯一值字段（例如主键）的 $orderby 结合使用。这可以避免在页面之间导航时出现数据“跳跃”或重复。

谨慎使用 $expand

“适度扩展。”

虽然 $expand 在减少网络调用次数方面非常强大，但深度或多个连接可能会严重降低 SAP 服务器的性能。评估一个 expand 是否优于两个优化的调用。
