SAP › Anatomía del Endpoint

Comprender la estructura de una URL de OData es fundamental. Cada punto de conexión sigue un patrón predecible que hace que la navegación sea intuitiva una vez que se conocen los componentes.

https://<host>:<port>/sap/opu/odata/sap/<SERVICE_NAME>/<EntitySet>(<Key>)?<QueryOptions>

Raíz del Servicio

La URL base hasta el nombre del servicio inclusive. Este es su punto de partida.
https://host/sap/opu/odata/sap/API_SALES_ORDER_SRV

Conjunto de Entidades (Entity Set)

Una colección de entidades (como una tabla de base de datos). Se añade a la raíz del servicio.
.../API_SALES_ORDER_SRV/A_SalesOrder

Entidad por Clave

Acceda a una entidad específica utilizando su clave entre paréntesis.
.../A_SalesOrder('0000000123')

i Propiedades de Navegación

Utilice las propiedades de navegación para recorrer las relaciones. Por ejemplo, para obtener los artículos de un pedido de ventas:
.../A_SalesOrder('0000000123')/to_Item. Consulte $metadata para descubrir las navegaciones disponibles.
