SAP › Selecting ($select)

The $select option limits which properties are returned. This is a key optimization technique.

Benefits of $select

  • Reduced payload Smaller response sizes mean faster transfers.
  • Faster processing The backend may skip expensive calculations for unselected fields.
  • Cleaner data Get only what you need—easier to work with downstream.

Examples

Basic Selection

$select=SalesOrder,CustomerID,CreationDate,TotalNetAmount

Combining with $expand

Select fields from the main entity AND the related entity.

$select=SalesOrder,CustomerID&$expand=to_Item($select=SalesOrderItem,Material,NetAmount)

Caution

Some endpoints (especially analytical ones with sap:semantics="aggregate") may restrict specific $select combinations.
