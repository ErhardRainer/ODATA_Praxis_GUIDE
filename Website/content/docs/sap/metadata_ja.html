SAP › メタデータ ($metadata)

$metadata エンドポイントは API の設計図です。エンティティタイプ、プロパティ、リレーションシップ、機能など、サービスの完全なスキーマを記述しています。

メタデータへのアクセス:

GET /sap/opu/odata/sap/API_SALES_ORDER_SRV/$metadata

内容の構成要素

  • EntityType (エンティティタイプ) 構造（プロパティ、データ型、キー）を定義します。クラス定義のようなものと考えてください。
  • EntitySet (エンティティセット) EntityType インスタンスの名前付きコレクションです。これが URL でクエリ対象となるものです。
  • NavigationProperty (ナビゲーションプロパティ) エンティティ間のリレーションシップを定義します (例: SalesOrder → SalesOrderItem)。

注目すべき SAP アノテーション

アノテーション 意味
sap:filterable="false"このプロパティを $filter で使用することはできません。
sap:sortable="false"このプロパティを $orderby で使用することはできません。
sap:creatable="false"POST 中にこのプロパティを設定することはできません。
sap:required-in-filter="true"$filter にこのプロパティを含める必要があります。

常に最初にメタデータを確認してください: クエリを作成する前に、$metadata を確認してフィールドの制限事項を把握してください。フィルタリング不可のフィールドでフィルタリングしようとするとエラーが返されます。
