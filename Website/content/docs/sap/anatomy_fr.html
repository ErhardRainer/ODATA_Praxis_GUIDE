SAP › Anatomie du Point de Terminaison

Comprendre la structure d'une URL OData est fondamental. Chaque point de terminaison suit un modèle prévisible qui rend la navigation intuitive une fois que vous connaissez les composants.

https://<host>:<port>/sap/opu/odata/sap/<SERVICE_NAME>/<EntitySet>(<Key>)?<QueryOptions>

Racine du Service

L'URL de base incluant le nom du service. C'est votre point de départ.
https://host/sap/opu/odata/sap/API_SALES_ORDER_SRV

Ensemble d'Entités (Entity Set)

Une collection d'entités (comme une table de base de données). Ajouté à la racine du service.
.../API_SALES_ORDER_SRV/A_SalesOrder

Entité par Clé

Accédez à une entité spécifique en utilisant sa clé entre parenthèses.
.../A_SalesOrder('0000000123')

i Propriétés de Navigation

Utilisez les propriétés de navigation pour parcourir les relations. Par exemple, para obtenir les articles d'une commande client :
.../A_SalesOrder('0000000123')/to_Item. Consultez $metadata pour découvrir les navigations disponibles.
