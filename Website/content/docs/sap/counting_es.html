SAP › Conteo de Registros

Hay dos formas de obtener el recuento de registros en OData, cada una de los cuales sirve para un propósito diferente.

$inlinecount (Parámetro)

Devuelve los datos y el número total de registros (ignorando $top y $skip) en un solo payload.

/SalesOrders?$inlinecount=allpages

Ideal para construir componentes de paginación en la interfaz de usuario.

$count (Recurso)

Devuelve solo un número simple (text/plain) que representa el recuento. No devuelve datos.

/SalesOrders/$count

Ideal para insignias o contadores rápidos en el panel de control.

Impacto en el Rendimiento

El conteo puede ser lento en tablas grandes en SAP. El sistema debe realizar primero un SELECT COUNT(*) en la base de datos antes de recuperar los datos para los parámetros $top y $skip. Utilícelo solo cuando sea necesario.
