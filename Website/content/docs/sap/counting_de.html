Zählen ($inlinecount / $count)

Oft müssen Sie wissen, wie viele Datensätze insgesamt vorhanden sind (z. B. für die Anzeige der Gesamtseitenanzahl in einer Liste).

V2 $inlinecount

Gibt die Daten UND die Gesamtanzahl in einem Paket zurück.

?$inlinecount=allpages

Das Ergebnis enthält ein Feld d.__count.

V4 $count

In OData V4 wurde dies zu $count=true vereinfacht.

?$count=true

Das Ergebnis enthält ein Feld @odata.count.

Ausschließlich Zählen

Wenn Sie NUR die Zahl ohne Daten benötigen (sehr performant):

.../A_SalesOrder/$count
