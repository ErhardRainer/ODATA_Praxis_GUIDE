SAP › Query Options Cheat Sheet

Query options let you filter, sort, page, and shape the data returned by OData services. All options start with $.

$filter

Restricts results to entities matching a condition.

$filter=SalesOrderType eq 'OR' and TotalNetAmount gt 1000

$select

Returns only specified properties, reducing payload size.

$select=SalesOrder,CustomerID,NetValue

$orderby

Sorts results. Use asc or desc.

$orderby=CreationDate desc,SalesOrder asc

$top & $skip

Pagination controls. $top limits results; $skip offsets the starting point.

$top=50&$skip=100

$count / $inlinecount

Get the total count of matching entities.

/A_SalesOrder/$count ?$inlinecount=allpages

$format

Specify response format. Default is usually Atom/XML in OData v2.

$format=json
