SAP › सॉर्टिंग और पेजिनेशन

उचित पेजिनेशन के लिए नियतात्मक (deterministic) सॉर्टिंग की आवश्यकता होती है। $orderby के बिना, रिकॉर्ड का क्रम अपरिभाषित होता है, जिससे पेजिंग करते समय रिकॉर्ड छूट सकते हैं या डुप्लिकेट हो सकते हैं।

सॉर्टिंग ($orderby)

asc (आरोही) या desc (अवरोही) का उपयोग करके परिणामों को सॉर्ट करें।

$orderby=CreationDate desc,SalesOrder asc

पेजिंग ($top & $skip)

  • $top=n: पहले n रिकॉर्ड लौटाएं।
  • $skip=n: पहले n रिकॉर्ड छोड़ें।
$top=50 // पहले 50 रिकॉर्ड
$top=50&$skip=50 // रिकॉर्ड 51-100
$top=50&$skip=100 // रिकॉर्ड 101-150

पेजिंग के लिए महत्वपूर्ण

हमेशा एक यूनिक की (Unique Key) द्वारा सॉर्ट करें!

यदि आप एक गैर-यूनिक फ़ील्ड (जैसे दिनांक) द्वारा सॉर्ट करते हैं, तो एक ही दिनांक वाले रिकॉर्ड अनुरोधों के बीच क्रम बदल सकते हैं। हमेशा प्राइमरी की जैसा एक यूनिक टाई-ब्रेकर जोड़ें:
$orderby=CreationDate desc, SalesOrderID asc
