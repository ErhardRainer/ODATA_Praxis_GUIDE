SAP › 参考概述

OData (开放数据协议) 是一种基于 REST 的标准化协议，用于构建和使用可查询的 API。在 SAP 生态系统中，OData 为 SAP Gateway 提供支持，使外部应用程序能够与 SAP 业务数据和流程进行交互。

RESTful 设计

使用标准 HTTP 方法（GET、POST、PUT、DELETE）并遵循 REST 约定。

可查询能力

丰富的查询选项，用于过滤、排序、分页和选择特定字段。

自描述性

$metadata 端点提供服务的完整架构信息。

为什么 SAP 使用 OData

  • 标准化： 跨服务的一致行为。
  • 互操作性： 适用于任何 HTTP 客户端。
  • Fiori 集成： Fiori 应用程序的本机 API 层。
