SAP › トラブルシューティング

SAP OData サービスの操作時によく発生する問題とその解決方法について説明します。

エラー: "Property 'X' is not a valid property"

EntityType に存在しないプロパティ名を使用している可能性があります。大文字小文字の区別を確認してください（例：SalesOrder と salesOrder）。OData は大文字小文字を区別します。

エラー: "Filter not supported" または無効なシステムクエリオプション

プロパティがフィルタリングを厳密に禁止している可能性があります (sap:filterable="false")。または、Gateway 実装でサポートされていない演算子を使用している可能性があります（例：数値フィールドでの substringof）。

ページング時のデータの欠落 / 重複

これは、非決定論的なソート（順序が確定しないソート）の典型的な症状です。$orderby 句にユニークキーを追加してください。

HTTP 401 Unauthorized / 403 Forbidden

認証情報を確認してください。また、SAP ユーザーが、特定の OData サービスにアクセスするために必要な PFCG ロールおよび権限オブジェクト (S_SERVICE) を持っているかどうかも確認してください。
