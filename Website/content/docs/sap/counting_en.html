SAP › Counting ($count)

Sometimes you just need to know "how many," or you need the total count alongside a page of data for a UI pager.

$count (Resource)

Returns the raw integer count of matching entities. No data is returned.

/A_SalesOrder/$count
/A_SalesOrder/$count?$filter=Status eq 'Open'

$inlinecount

Returns the data plus the total count in the response wrapper (__count).

/A_SalesOrder?$top=10&$inlinecount=allpages

Performance Note

Calculating the total count ($inlinecount=allpages) can be performance-intensive on large datasets because the database has to count all matching rows, even if you only requested the top 10. Use it only when necessary.
