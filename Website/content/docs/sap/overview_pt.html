OData (Open Data Protocol) é um protocolo padronizado baseado em REST para criar e consumir APIs consultáveis. No ecossistema SAP, o OData alimenta o SAP Gateway, permitindo que aplicativos externos interajam com dados e processos de negócios SAP.

Design RESTful

Utiliza métodos HTTP padrão (GET, POST, PUT, DELETE) e segue as convenções REST.

Capacidade de Consulta

Opções de consulta ricas para filtragem, ordenação, paginação e seleção de campos específicos.

Auto-descritivo

O endpoint $metadata fornece informações completas do esquema para o serviço.

Por que a SAP utiliza OData

  • Padronização: Comportamento consistente entre os serviços.
  • Interoperabilidade: Funciona com qualquer cliente HTTP.
  • Integração Fiori: Camada de API nativa para aplicativos Fiori.
