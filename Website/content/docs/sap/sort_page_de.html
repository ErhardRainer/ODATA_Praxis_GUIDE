Sortierung & Paginierung

$orderby

Sortierung

Steuern Sie die Reihenfolge der Ergebnisse. Standardmäßig wird aufsteigend sortiert (asc).

Absteigend (Neu zu Alt)

$orderby=CreatedAt desc

Mehrfache Sortierung

$orderby=Priority desc, Name asc
$top / $skip

Paginierung

Laden Sie Daten in kleinen "Häppchen", um Timeouts zu vermeiden und die UX zu verbessern.

// Seite 3 laden (10 Datensätze pro Seite)

GET /A_SalesOrder?

$top=10 &

$skip=20
