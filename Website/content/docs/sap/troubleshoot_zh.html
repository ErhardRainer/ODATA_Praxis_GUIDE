SAP › 故障排除

使用 SAP OData 服务时的常见问题及其解决方法。

错误："Property 'X' is not a valid property"

您可能使用了 EntityType 中不存在的属性名称。检查大小写敏感性（例如，SalesOrder 与 salesOrder）。OData 是区分大小写的。

错误："Filter not supported" 或无效的系统查询选项

该属性可能严格禁止过滤 (sap:filterable="false")。或者，您可能使用了 gateway 实现不支持的运算符（例如，在数字字段上使用 substringof）。

分页中的数据缺失/重复

这是非确定性排序的典型症状。在 $orderby 子句中添加唯一键。

HTTP 401 Unauthorized / 403 Forbidden

验证您的凭据。还要检查 SAP 用户是否具有访问特定 OData 服务所需的 PFCG 角色和授权对象 (S_SERVICE)。
