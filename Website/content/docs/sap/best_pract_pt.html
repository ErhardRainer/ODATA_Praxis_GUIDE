SAP OData › Melhores Práticas

Siga estas diretrizes para garantir que suas integrações OData com SAP sejam eficientes, escaláveis e amigáveis ao desempenho do sistema.

Seja Seletivo ($select)

"Nunca peça o que você não precisa."

O SAP Gateway tem que buscar cada campo do banco de dados e convertê-lo para XML/JSON. Ao usar $select, você reduz drasticamente o tempo de processamento no ABAP e o tamanho do pacote de dados transferido pela rede.

Filtre Cedo, Filtre Sempre ($filter)

"Deixe o banco de dados fazer o trabalho pesado."

Nunca busque 10.000 registros para filtrar apenas 10 no seu código JavaScript. Use os filtros OData para garantir que o SAP execute instruções SQL otimizadas e retorne apenas o que é estritamente necessário.

Paginação Determinística

"A consistência é a chave para uma boa UX."

Sempre combine $top e $skip com um $orderby contendo pelo menos um campo de valor único (ex: chave primária). Isso evita "saltos" ou duplicação de dados ao navegar entre as páginas.

Cuidado com $expand

"Expanda com moderação."

Embora o $expand seja poderoso para reduzir o número de chamadas de rede, conexões profundas ou múltiplas podem degradar severamente a performance no servidor SAP. Avalie se um expand é melhor do que duas chamadas otimizadas.
