SAP › Best Practices

Optimizing OData queries is essential for ensuring the stability and speed of your SAP applications.

1

Select Only What You Need

Always use $select to retrieve only the fields required for your process. This reduces database load, application server memory usage, and network payload.

2

Filter on Keys & Indexed Fields

Filtering on non-indexed columns causes full table scans in the HANA database. Prefer filtering on Primary Keys or indexed business keys.

3

Use Correct Paging

When retrieving large datasets, always use server-side paging ($top/$skip) and ensure deterministic sorting with a unique key in $orderby.

4

Check Metadata Capabilities

Don't assume all fields are filterable. Check sap:filterable and sap:sortable annotations in the $metadata to avoid runtime errors.
