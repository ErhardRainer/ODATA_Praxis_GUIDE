SAP › Endpunkt-Anatomie

Das Verständnis der Struktur einer OData-URL ist grundlegend. Jeder Endpunkt folgt einem vorhersehbaren Muster, das die Navigation intuitiv macht, sobald man die Komponenten kennt.

https://<host>:<port>/sap/opu/odata/sap/<SERVICE_NAME>/<EntitySet>(<Key>)?<QueryOptions>

Service Root

Die Basis-URL bis einschließlich zum Servicenamen. Dies ist Ihr Startpunkt.
https://host/sap/opu/odata/sap/API_SALES_ORDER_SRV

Entity Set

Eine Sammlung von Entitäten (vergleichbar mit einer Datenbanktabelle). Wird an den Service Root angehängt.
.../API_SALES_ORDER_SRV/A_SalesOrder

Entity by Key

Zugriff auf eine spezifische Entität über ihren Schlüssel in Klammern.
.../A_SalesOrder('0000000123')

i Navigation Properties

Nutzen Sie Navigations-Eigenschaften, um Beziehungen zu folgen. Beispiel für Positionen eines Auftrags:
.../A_SalesOrder('0000000123')/to_Item. Prüfen Sie $metadata, um verfügbare Navigationen zu finden.
