SAP › Endpoint Anatomy

Understanding the structure of an OData URL is fundamental. Every endpoint follows a predictable pattern that makes navigation intuitive once you know the components.

https://<host>:<port>/sap/opu/odata/sap/<SERVICE_NAME>/<EntitySet>(<Key>)?<QueryOptions>

Service Root

The base URL up to and including the service name. This is your starting point.
https://host/sap/opu/odata/sap/API_SALES_ORDER_SRV

Entity Set

A collection of entities (like a database table). Appended to the service root.
.../API_SALES_ORDER_SRV/A_SalesOrder

Entity by Key

Access a specific entity using its key in parentheses.
.../A_SalesOrder('0000000123')

i Navigation Properties

Use navigation properties to traverse relationships. For example, to get items of a sales order:
.../A_SalesOrder('0000000123')/to_Item. Check $metadata to discover available navigations.
