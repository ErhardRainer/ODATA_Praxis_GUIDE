SAP › Resumen de Referencia

OData (Open Data Protocol) es un protocolo estandarizado basado en REST para crear y consumir APIs consultables. En el ecosistema SAP, OData impulsa SAP Gateway, permitiendo que las aplicaciones externas interactúen con los datos y procesos comerciales de SAP.

Diseño RESTful

Utiliza métodos HTTP estándar (GET, POST, PUT, DELETE) y sigue las convenciones REST.

Capacidad de Consulta

Ricas opciones de consulta para filtrar, ordenar, paginar y seleccionar campos específicos.

Auto-descriptivo

El punto de conexión $metadata proporciona información completa del esquema para el servicio.

Por qué SAP utiliza OData

  • Estandarización: Comportamiento consistente en todos los servicios.
  • Interoperabilidad: Funciona con cualquier cliente HTTP.
  • Integración Fiori: Capa de API nativa para aplicaciones Fiori.
