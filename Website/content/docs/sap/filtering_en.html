SAP › Filtering ($filter)

Effective filtering is crucial for performance. It restricts results serverseide.

Comparison Operators

Operator Meaning Example
eqEqualStatus eq 'A'
neNot equalStatus ne 'X'
gtGreater thanAmount gt 100
geGreater or equalAmount ge 100
ltLess thanQuantity lt 50
leLess or equalQuantity le 50

Common Filtering Patterns

Date Filtering (OData V2)

Orders created in 2024:

$filter=CreationDate ge datetime'2024-01-01T00:00:00' and CreationDate le datetime'2024-12-31T23:59:59'

String Filtering

Exact match or starts with:

$filter=CustomerID eq 'CUST001'
$filter=startswith(CustomerName,'ACME')

Performance Tip

Use key fields and indexed properties in filters for best performance. Avoid using substringof on non-indexed fields as it may result in full table scans.
