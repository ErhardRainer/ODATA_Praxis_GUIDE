SAP › 排序和分页

适当的分页需要确定性的排序。如果没有 $orderby，记录的顺序是不确定的，这可能会在分页时导致记录缺失或重复。

排序 ($orderby)

使用 asc（升序）或 desc（降序）对结果进行排序。

$orderby=CreationDate desc,SalesOrder asc

分页 ($top & $skip)

  • $top=n：返回前 n 条记录。
  • $skip=n：跳过前 n 条记录。
$top=50 // 前 50 条记录
$top=50&$skip=50 // 第 51-100 条记录
$top=50&$skip=100 // 第 101-150 条记录

分页的关键

始终按唯一键排序！

如果您按非唯一字段（例如日期）排序，则具有相同日期的记录在请求之间可能会改变顺序。始终添加一个唯一的决胜字段，如主键：
$orderby=CreationDate desc, SalesOrderID asc
