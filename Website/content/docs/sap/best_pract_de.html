Best Practices & Performance

Effiziente OData-Abfragen schonen die Systemressourcen Ihres SAP-Backend und verbessern die Antwortzeiten.

1. Filtern im Backend

Nutzen Sie $filter so weit wie möglich. Laden Sie niemals alle Daten, um sie dann im JavaScript/Frontend zu filtern.

2. Nur benötigte Felder

SAP Tabellen haben oft hunderte Spalten. Verwenden Sie $select, um nur die 5-10 Felder zu holen, die Sie wirklich anzeigen.

3. Batch-Verarbeitung ($batch)

Kombinieren Sie mehrere Requests zu einem einzigen HTTP-Call. Das eliminiert den Network-Overhead für jeden einzelnen Request.

4. Typsichere Filter

Stellen Sie sicher, dass GUIDs, Datumsangaben und Zahlen korrekt formatiert sind (z.B. datetime'...'), sonst muss SAP den Filter mühsam konvertieren oder schlägt fehl.

"Ein guter OData-Request ist wie ein Skalpell – scharf und präzise. Ein schlechter Request ist wie ein Staubsauger – er saugt alles auf und macht das System langsam."
