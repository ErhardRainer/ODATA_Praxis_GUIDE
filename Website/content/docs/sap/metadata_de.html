Metadaten ($metadata)

Der wichtigste Endpunkt für Entwickler. Er liefert ein XML-Dokument, das das gesamte Datenmodell des Services beschreibt.

Wie man sie aufruft

Hängen Sie einfach $metadata am Ende des Service Root an:

/sap/opu/odata/sap/API_SALES_ORDER_SRV/$metadata

Entitätstypen & Mengen

Listet alle Tabellen (EntitySets) und deren Struktur (Properties) auf. Achten Sie auf Nullable="false" für Pflichtfelder.

Assoziationen & Navigation

Definiert die Beziehungen zwischen Entitäten ($expand). So wissen Sie, wie Sie von einem Header zu seinen Positionen gelangen.

Profi-Tipp für SAP

SAP OData Services enthalten oft SAP-Annotationen innerhalb der Metadaten, die wichtige Business-Regeln beschreiben, wie sap:creatable="false" oder sap:label="Auftragsnummer".
