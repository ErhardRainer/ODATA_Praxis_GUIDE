SAP OData › Mejores Prácticas

Siga estas directrices para garantizar que sus integraciones OData con SAP sean eficientes, escalables y respetuosas con el rendimiento del sistema.

Sea Selectivo ($select)

"Nunca pidas lo que no necesitas."

SAP Gateway tiene que recuperar cada campo de la base de datos y convertirlo a XML/JSON. Al usar $select, reduce drásticamente el tiempo de procesamiento en ABAP y el tamaño del paquete de datos transferido por la red.

Filtre Temprano, Filtre Siempre ($filter)

"Deja que la base de datos haga el trabajo pesado."

Nunca recupere 10.000 registros para filtrar solo 10 en su código JavaScript. Utilice los filtros OData para asegurarse de que SAP ejecute sentencias SQL optimizadas y devuelva solo lo que es estrictamente necesario.

Paginación Determinista

"La consistencia es la clave para una buena UX."

Combine siempre $top y $skip con un $orderby que contenga al menos un campo de valor único (p. ej., clave primaria). Esto evita "saltos" o duplicación de datos al navegar entre páginas.

Cuidado con $expand

"Expanda con moderación."

Aunque $expand es potente para reducir el número de llamadas de red, las conexiones profundas o múltiples pueden degradar seriamente el rendimiento en el servidor SAP. Evalúe si un expand es mejor que dos llamadas optimizadas.
