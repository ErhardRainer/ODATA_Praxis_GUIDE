SAP › Metadatos ($metadata)

El punto de conexión $metadata es el plano de su API. Describe el esquema completo del servicio: tipos de entidad, propiedades, relaciones y capacidades.

Acceso a los Metadatos:

GET /sap/opu/odata/sap/API_SALES_ORDER_SRV/$metadata

¿Qué hay dentro?

  • EntityType Define la estructura: propiedades, tipos de datos y claves. Piense en ello como una definición de clase.
  • EntitySet Una colección con nombre de instancias de EntityType. Estoo es lo que se consulta en las URL.
  • NavigationProperty Define las relaciones entre entidades (por ejemplo, SalesOrder → SalesOrderItem).

Anotaciones SAP a tener en cuenta

Anotación Significado
sap:filterable="false"No se puede usar esta propiedad en $filter
sap:sortable="false"No se puede usar esta propiedad en $orderby
sap:creatable="false"No se puede establecer esta propiedad durante el POST
sap:required-in-filter="true"Debe incluir esta propiedad en $filter

Compruebe siempre los metadatos primero: Antes de construir consultas, revise el $metadata para comprender las restricciones de los campos. Intentar filtrar por un campo no filtrable devolverá un error.
