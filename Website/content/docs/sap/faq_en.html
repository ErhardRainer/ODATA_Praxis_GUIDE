SAP › Frequently Asked Questions

What's the difference between OData v2 and v4 in SAP?

OData v2 is the standard for most SAP Gateway implementations. v4 is the newer, more efficient standard used in modern S/4HANA systems. v4 offers better performance, simplified metadata, and more powerful query capabilities.

Why am I getting 'Property cannot be filtered' errors?

This happens when a field is marked with sap:filterable="false" in the $metadata. SAP often restricts filtering on calculated fields or large text fields to ensure database performance.

How do I handle authentication for OData calls?

SAP supports Basic Auth, OAuth 2.0 (recommended), and SAML. For browser-based apps, Principal Propagation is often used. Always use HTTPS to protect credentials.

What's the maximum number of records I can retrieve?

SAP systems often have server-side limits (e.g., 1000 records). If you need more, you must use **paging** (following the __next link or using $skip/$top).

How do I call OData functions or actions?

Functions (GET) and Actions (POST) are custom operations defined in the $metadata. You call them by appending the name to the service URL, e.g., .../GetQuickStats() or .../ReleaseOrder.

Can I update multiple records in a single request?

Yes, using **OData batch requests** ($batch). You can bundle multiple GET, POST, PATCH, or DELETE operations into a single HTTP POST. SAP supports both atomic (all-or-nothing) and non-atomic processing using multipart/mixed content types.

How do I handle deep inserts (creating related entities)?

Deep inserts allow you to create a parent and child entities (like a Sales Order and its Items) in a single POST request by nesting the child data within the parent JSON structure.

What does the CSRF token error mean?

SAP requires a CSRF token for all state-changing requests (POST/PUT/DELETE). You must first fetch a token via a GET request with the header x-csrf-token: fetch, then send the received token back in your follow-up write request.

Legacy Concepts

EntitySet vs. EntityType?

EntityType is the "Class" (Blueprint), EntitySet is the "Table" (Instance collection).

JSON vs. XML?

Always prefer JSON. It is lighter, faster to parse, and uses less bandwidth.
