SAP › Sorting & Paging

Proper pagination requires deterministic sorting. Without $orderby, the order of records is undefined, which can lead to missing or duplicate records when paging.

Sorting ($orderby)

Sort results using asc (ascending) or desc (descending).

$orderby=CreationDate desc,SalesOrder asc

Paging ($top & $skip)

  • $top=n: Return the first n records.
  • $skip=n: Skip the first n records.
$top=50 // First 50 records
$top=50&$skip=50 // Records 51-100
$top=50&$skip=100 // Records 101-150

Crucial for Paging

Always sort by a unique key!

If you sort by a non-unique field (e.g., date), records with the same date might change order between requests. Always add a unique tie-breaker like the primary key:
$orderby=CreationDate desc, SalesOrderID asc
