SAP › リファレンス概要

OData (Open Data Protocol) は、クエリ可能な API を構築および利用するための標準化された REST ベースのプロトコルです。SAP エコシステムでは、OData は SAP Gateway を駆動し、外部アプリケーションが SAP のビジネスデータやプロセスと対話できるようにします。

RESTful デザイン

標準的な HTTP メソッド (GET, POST, PUT, DELETE) を使用し、REST の規則に従います。

クエリ機能

フィルタリング、ソート、ページング、および特定のフィールドの選択のための豊富なクエリオプションを提供します。

自己記述型

$metadata エンドポイントは、サービスの完全なスキーマ情報を提供します。

SAP が OData を使用する理由

  • 標準化: サービス間で一貫した動作を実現します。
  • 相互運用性: あらゆる HTTP クライアントで動作します。
  • Fiori への統合: Fiori アプリ向けのネイティブ API レイヤーとして機能します。
