SAP › Aperçu de la Référence

OData (Open Data Protocol) est un protocole standardisé basé sur REST pour la création et la consommation d'API interrogeables. Dans l'écosystème SAP, OData alimente SAP Gateway, permettant aux applications externes d'interagir avec les données et les processus métier de SAP.

Conception RESTful

Utilise les méthodes HTTP standard (GET, POST, PUT, DELETE) et suit les conventions REST.

Capacité de Requête

Options de requête riches pour le filtrage, le tri, la pagination et la sélection de champs spécifiques.

Auto-descriptif

Le point de terminaison $metadata fournit des informations complètes sur le schéma du service.

Pourquoi SAP utilise OData

  • Standardisation : Comportement cohérent à travers les services.
  • Interopérabilité : Fonctionne avec n'importe quel client HTTP.
  • Intégration Fiori : Couche d'API native pour les applications Fiori.
