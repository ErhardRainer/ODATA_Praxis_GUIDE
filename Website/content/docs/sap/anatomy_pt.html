SAP › Anatomia do Endpoint

Compreender a estrutura de uma URL OData é fundamental. Cada endpoint segue um padrão previsível que torna a navegação intuitiva uma vez que você conhece os componentes.

https://<host>:<port>/sap/opu/odata/sap/<SERVICE_NAME>/<EntitySet>(<Key>)?<QueryOptions>

Raiz do Serviço (Service Root)

A URL base até e incluindo o nome do serviço. Este é o seu ponto de partida.
https://host/sap/opu/odata/sap/API_SALES_ORDER_SRV

Conjunto de Entidades (Entity Set)

Uma coleção de entidades (como uma tabela de banco de dados). Anexado à raiz do serviço.
.../API_SALES_ORDER_SRV/A_SalesOrder

Entidade por Chave (Entity by Key)

Acesse uma entidade específica usando sua chave entre parênteses.
.../A_SalesOrder('0000000123')

i Propriedades de Navegação

Use propriedades de navegação para percorrer relacionamentos. Por exemplo, para obter os itens de uma ordem de vendas:
.../A_SalesOrder('0000000123')/to_Item. Verifique o $metadata para descobrir as navegações disponíveis.
