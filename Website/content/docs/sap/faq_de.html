Häufig gestellte Fragen (FAQ)

Was ist der Unterschied zwischen OData V2 und V4 in SAP?
V2 ist der Standard für ältere SAP-Systeme (Gateway/ECC) und bietet eine tiefere Integration in das klassische ABAP-Dictionary. V4 ist moderner, effizienter bei der Payload-Größe und wird für neuere S/4HANA-Entwicklungen bevorzugt. Die Syntax für Filter und Expands unterscheidet sich leicht.
Wie gehe ich mit CSRF-Tokens bei POST-Requests um?
1. Führen Sie einen GET-Request (z.B. auf den Service Root) mit dem Header x-csrf-token: fetch aus.
2. Lesen Sie das Token aus dem Response-Header x-csrf-token aus.
3. Senden Sie dieses Token in Ihrem POST/PUT/DELETE-Request im Header mit.
Können OData-Abfragen die SAP-Datenbank langsam machen?
Ja, besonders wenn keine Filter auf indizierte Felder angewendet werden oder massive $expand-Ketten über viele Tabellen genutzt werden. Nutzen Sie immer $top und $select, um die Last zu begrenzen.
Was ist $batch und wann sollte ich es nutzen?
$batch erlaubt es, mehrere OData-Operationen in einem einzigen HTTP-Request zu bündeln. Dies ist extrem nützlich, wenn Sie viele kleine Änderungen gleichzeitig speichern wollen, ohne für jede Änderung einen eigenen Netzwerk-Call auszuführen.
