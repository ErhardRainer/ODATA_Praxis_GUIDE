SAP › Ordenação e Paginação

A paginação adequada requer uma ordenação determinística. Sem o $orderby, a ordem dos registros é indefinida, o que pode levar à perda ou duplicidade de registros ao paginar.

Ordenação ($orderby)

Ordene os resultados usando asc (crescente) ou desc (decrescente).

$orderby=CreationDate desc,SalesOrder asc

Paginação ($top & $skip)

  • $top=n: Retorna os primeiros n registros.
  • $skip=n: Pula os primeiros n registros.
$top=50 // Primeiros 50 registros
$top=50&$skip=50 // Registros 51-100
$top=50&$skip=100 // Registros 101-150

Crucial para Paginação

Sempre ordene por uma chave única!

Se você ordenar por um campo não único (ex: data), registros com a mesma data podem mudar de ordem entre as solicitações. Sempre adicione um critério de desempate único, como a chave primária:
$orderby=CreationDate desc, SalesOrderID asc
